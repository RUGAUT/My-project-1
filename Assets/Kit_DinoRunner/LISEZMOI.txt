KIT DINO RUNNER – Cours d'initiation à Unity 2D
================================================

COMMENT IMPORTER DANS UNITY
1. Dézippez le dossier, puis glissez les sous-dossiers dans Assets/ de votre projet Unity
   (par exemple Assets/Sprites/Personnages, Assets/Sprites/Obstacles…).
2. Sélectionnez TOUTES les images, puis dans l'Inspector :
   - Texture Type : Sprite (2D and UI)
   - Pixels Per Unit : 16      (le même pour tout le kit !)
   - Filter Mode : Point (no filter)
   - Compression : None
   - cliquez sur Apply
3. Pour les planches d'animation (Sprite Mode : Multiple), ouvrez le Sprite Editor
   puis Slice > Type : Grid By Cell Size, avec la taille indiquée ci-dessous > Slice > Apply.
